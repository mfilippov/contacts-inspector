# Security

Contacts Inspector runs entirely on your Mac: it talks only to Apple's Contacts database, the
Contacts app (AppleScript) and, if you sign in, to Telegram through TDLib. Nothing is sent anywhere else.

If you find a vulnerability — for example a way to leak contact data, the Telegram session or the
API keys — please report it privately through GitHub's
[private vulnerability reporting](https://github.com/mfilippov/contacts-inspector/security/advisories/new)
rather than in a public issue. You should get a reply within a week.

Only the latest release is supported.
